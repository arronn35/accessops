## New operational contracts

- `POST /api/privacy/delete-scan-data` → `202 { ok, job }`; `GET` → latest job status. Requires `{ "confirm": "DELETE" }` and `delete_scans` permission.
- `DELETE /api/scans/:id` → deletes one finished scan and its artifacts (409 while running).
- `GET /api/healthz?deep=1` → adds `checks.worker { ok, lastSeenSecondsAgo }` and top-level `degraded`.
- Firestore TTL policies to enable once (console): `rateLimits.expireAt`, `workerHeartbeats.expireAt`.
- New env: `CRON_SECRET` (prod, recommended), `WORKER_HEARTBEAT_FRESH_MS` (optional), `E2E_FIREBASE_PROJECT_ID/CLIENT_EMAIL/PRIVATE_KEY` + `E2E_FIXTURE_URL` (staging e2e only).
