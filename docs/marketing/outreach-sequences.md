# Percevia AI Outreach Sequences

Updated: 2026-06-27

Use plain text. Keep emails short. Do not attach reports in the first email. Ask for permission before scanning a third-party site beyond a light manual review.

## Shared Footer

Use or adapt this footer on all cold outbound messages:

```text
Percevia AI by maitrico
Accessibility operations, not one-click compliance.
Website: https://percevia-chi.vercel.app

If this is not relevant, reply "not interested" and I will not contact you again.
```

Add the company's physical address when the production sender identity is finalized.
